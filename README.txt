SCAPE PHONE V4

Cambios principales:
- Inicio simplificado: solo muestra la actividad actual.
- Elimina Próxima actividad, Consejo y el botón inferior de redes.
- La actividad actual se calcula según la hora y el horario del día.
- El contador baja en tiempo real y al terminar cambia a la siguiente actividad.
- Si no hay actividades programadas, muestra el mensaje "No tienes actividades asignadas" en la tarjeta morada.
- Redes sociales en modo híbrido: los logos pueden abrir las redes reales en una nueva pestaña.
- Mientras la pestaña real está abierta, Scape phone conserva la hora de inicio y el límite de uso.
- Al regresar a Scape phone después del límite, aparece el aviso correspondiente.
- Se mantiene el flujo de 5 minutos más y el temporizador.
V4.4: La sección Redes sociales ahora tiene un botón visible de Scape phone para volver cuando quieras. Al abrir una red se muestra de inmediato un aviso no bloqueante indicando la actividad actual; también intenta enviar una notificación del navegador si el usuario concede permiso.
